# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature. Include reproduction steps, affected code, impact, and a suggested remediation when possible. Do not include secrets, personal data, or live malicious samples.

## Safe-use boundary

Do not use these tools on third-party systems without explicit authorization. BehaviorLab is intentionally limited to a caller-selected workspace and loopback networking. SafeTrace performs static analysis and never executes its input.
